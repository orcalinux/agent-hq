BEFORE YOU GET STARTED

Good questions.
Straight answers.

Do I need several AI subscriptions?+

No. A single supported connection is enough. With multiple connections, Agent HQ can choose models for different task complexities and switch providers if one runs out of quota. You can also choose models manually.

Is Agent HQ free?+

The application is free and open source under the MIT license. Your model provider's subscription, API charges, and usage limits still apply. You can also connect local models through Ollama.

Does my code stay on my computer?+

The app and its project memory run locally. When you use a cloud model, the task and relevant code context are sent to that provider. Use a local model if you want model inference on your own machine. Agent HQ also contacts GitHub when checking for updates.

How do agents get better over time?+

They keep project-specific lessons from your instructions and review feedback. Relevant lessons are included in later prompts; this is persistent context, not model training. Inspect, edit, or remove lessons from the app.

Can I use a gateway like Magpie?+

Yes. Connect a local Magpie gateway in Connections to use its models and routing groups. It is optional; you can connect supported CLIs, APIs, and Ollama directly.

What should I know before installing?+

Agent HQ is an evolving project. Installers are not code-signed, so your OS may show a warning. Agents propose file changes; they do not have autonomous shell access or separate worktrees. The app's integrated terminal is for you. Gemini CLI has not been verified on the maintainer's machine. See the roadmap for current limitations and planned work.
