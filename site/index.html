How it works

  1. Connect

    One subscription or API key is enough. Agent HQ detects Claude Code, Codex, Gemini CLI, Ollama and a Magpie gateway on your computer.

  2. Plan

    Tell Sovereign, the orchestrator, what you need. It proposes tasks, agents and models. You edit and approve before anything runs.

  3. Build

    Agents work in dependency order, in parallel where they can. A senior reviews juniors, and QA can send work back once.

  4. Apply

    Changes arrive as diffs. Apply them yourself, or choose Auto-apply or Full access and undo any file later.

Built to be trusted

  • You set the trust level

    Ask every time by default. Auto-apply writes QA-approved changes. Full access also skips plan approval, and says exactly what it allows first.

  • Spending limits

    Per-run and per-agent caps for cost, tokens, time and model calls. You are warned at 80% and the run stops at 100%.

  • No silent overwrites

    Two agents proposing the same file are flagged as a conflict and never applied behind your back.

  • Survives crashes

    The active run is journaled. After a crash or restart, finished work and pending approvals are still there.

  • The right model per task

    Tasks are rated simple, standard or complex and sent to the strongest connected model of that level, with failover when a provider runs out of credit.

  • Local and open

    Everything runs on your machine. Stored API keys are encrypted. MIT licensed, with a public roadmap.

Quick start

  1. Install the .deb, .rpm, AppImage, or the Windows or macOS installer from Releases.
  2. Open Connections and connect a provider.
  3. Open a project folder, then describe the task to Sovereign.
  4. Review the plan, approve it, and review the changes.

Once a release includes SHA256SUMS.txt, verify a download with sha256sum -c SHA256SUMS.txt.

Limitations, stated plainly

  • Installers are not code-signed yet.
  • Runs are controlled by the app. If it quits mid-run, finished work is kept and the run resumes from where it stopped, automatically only in Full access.
  • Agents propose file changes; they do not get a shell, and they do not edit in parallel worktrees.
  • No benchmark ranks models yet. The small test suite is a connection check; every model passed it.
  • Gemini CLI support is untested on the maintainer's machine.
